# LeetCode Top 500 教学

React + TypeScript 构建的中文交互式算法课程，提供 500 道高频题目录、Python 深度讲义、逐步运行演示、浏览器内代码执行与提交验证、分类筛选和本地学习进度。

## 启动

```bash
npm install
npm run dev
```

生产构建：`npm run build`。

## 功能

- 500 道高频题目录，支持按题号/标题/标签搜索，按分类、难度、完成状态筛选，以及随机抽题
- 讲义含题意改写、算法直觉、暴力到最优的推导、Python 实现、逐步运行推演、复杂度与易错点
- 浏览器内 Python 练习区：可编辑代码、自定义测试、`Cmd/Ctrl + Enter` 运行（加 `Shift` 验证提交）
- 其中 406 道题的示例测试由讲义示例自动生成，打开即可直接验证
- 上一题/下一题导航与列表方向键切换
- 学习进度保存在浏览器，可导出为 JSON 备份并跨设备导入

## 内容说明

题意均为原创改写摘要，完整题面通过页面中的官方链接访问。题单参考 LeetCode Hot 100、Top Interview 150、高赞经典题与高频面试题，并扩展到 500 道。

“验证提交”会运行你编写的自定义 `assert` 测试，不等同于 LeetCode 官方隐藏测试。首次运行 Python 时，浏览器需要联网加载 Pyodide 运行资源。
